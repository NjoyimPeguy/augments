# Augments skills

These engineering skills are installed in this project, invoked as `augments:<name>`.

Before acting on any software-engineering request, check whether an augments skill fits the task and invoke it to anchor the work — the skills work alongside your judgment, adding the gates and checks it cannot supply alone. The skills cover the whole SDLC — planning, analysis, design, implementation, testing, deployment, and maintenance — plus cross-cutting tools (orientation, interviewing an unclear request, worktrees, parallel agents, handoff). If you are unsure which fits, invoke `augments:using-augments` first for the map.

If, after checking, no skill genuinely applies, proceed normally — this is a discipline to reach for the right tool, not a gate that blocks trivial work.
