# Augments skills — non-negotiable routing

Augments installs engineering skills for the whole SDLC. The full list with triggers is already in your Skill tool. They are not optional suggestions — they are the procedures this project runs on, and skipping one that applies is the mistake they exist to prevent.

Before you start any non-trivial request — and before any tool call that begins the work — run this check, every time:

1. Could a skill, or a chain of skills, apply here at all? Treat "too simple", "I already know this", "no time", and "I'll just do it directly" as signals to CHECK, not to skip — they are exactly how work gets done wrong.
2. If anything could apply, there is no judgment call: invoke it before acting. If a whole phase applies, walk its chain (e.g. define-goals → feasibility-check → scope-it) — don't fire one skill and stop.
3. Proceed without a skill only after you have actually scanned the list and nothing fits — and say so in one line.

The routing check is non-negotiable; which skill (or none) is all you decide.
