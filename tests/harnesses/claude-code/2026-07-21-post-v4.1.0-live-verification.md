## The two hook errors from 2026-07-15

- **Read-only filesystem in SessionStart:** not reproduced — zero matches in
  the kept streams. Presumed an artifact of the unauthenticated 2026-07-15
  environment.
- **Duplicate hooks:** reproduced verbatim (`Hook load failed: Duplicate
  hooks file detected: ./hooks/hooks.json resolves to already-loaded file …`).
  Root cause: Claude Code auto-loads the conventional `hooks/hooks.json`, and
  `.claude-plugin/plugin.json` *also* named it in a `hooks` key, so it loaded
  twice. Fixed by dropping the manifest key; the post-fix probe stream has no
  hook error and routing still fires, so the SessionStart nudge demonstrably
  survives the removal.
